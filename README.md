# Metalbabble-Web

This repo contains pages and content that make up the http://www.metalbabble.com/ website!

# What's here

- `/` the root contains my main home page 
- `/home` also contains the main home page (but will likely be phased out to just use the root version)
- `/atari` the page to download my homebrew Atari games
- `/super-sand-castles` a page dedicated to one of my games, Super Sand Castles

# And...?

This repo is set up to publish from the main branch to GitHub pages, and http://www.metalbabble.com/ itself links to these areas!
